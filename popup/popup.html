Gemini API keys

Dán link lẫn text, extension sẽ tự nhận diện và mở tab theo thứ tự.

Hướng dẫn
  • Fast Quiz — Chế độ làm quiz hàng loạt (gộp nhảy bài, làm bài, nộp). Khi đang chạy, dừng bằng nút Dừng trên popup giữa màn hình.
  • Nhảy — Chọn bài assignment/quiz chưa hoàn thành đầu tiên trong danh sách module.
  • Quiz — Lấy nội dung câu hỏi trên trang; nếu bật GMN auto ở trên thì gọi Gemini gợi ý đáp án.
  • Copy — Copy toàn bộ câu hỏi (định dạng 1/A) ra clipboard.
  • Paste — Điền đáp án từ ô trong menu hoặc clipboard, rồi nộp bài.
  • Skip — Đánh dấu hoàn thành video/reading trong tuần đang xem.
  • Ẩn mục đã hoàn thành — Ẩn dòng đã tick trên danh sách Coursera.
  • Copy quiz / Auto điền — Làm quiz từ popup khi đang ở trang bài.
  • Mở link — Nhận URL trong text và mở nhiều tab.
  • Thu gọn menu — Bấm icon Crush trên trang để gấp menu thành nút tròn.
